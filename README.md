 # 🚆 Indian Railway Passenger & Operations Analytics

## 📊 Project Overview

**Indian Railway Passenger & Operations Analytics** is an interactive Excel-based data analytics project designed to analyze railway passenger and operational data for the years **2024 and 2025**.

The project transforms raw railway data into meaningful insights using **Microsoft Excel, Power Query, Power Pivot, Data Model, DAX, Pivot Tables, Pivot Charts, and Slicers**.

The dashboard provides a visual and interactive way to understand booking patterns, revenue performance, passenger behavior, and train operations.

---

## 🎯 Project Objective

The main objective of this project is to analyze railway data from different perspectives and convert raw data into meaningful business insights.

The project focuses on three major analytical areas:

1. **Booking & Revenue Intelligence**
2. **Customer Intelligence**
3. **Train & Operations Analysis**

## 🧩 Data Model

The project uses a structured data model consisting of multiple dimension tables and a fact table.

The model includes dimensions such as:

- Dim Date
- Dim Customer
- Dim Train
- Dim Station
- Dim Class
- Dim Staff
- Dim Quota

These tables are connected through relationships in the Excel Data Model.
